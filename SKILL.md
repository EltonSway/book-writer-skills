# Скилл «Книга» (Book Publishing & Generation)

Скилл для работы с книгой «Фреймворки жизни» (и аналогичными проектами формата «разворот: слева текст, справа векторная SVG-схема»). Включает правила вёрстки, команды сборки, валидацию геометрии и требования издательских платформ (Литрес Самиздат, Ridero/T8).

---

## 1. Архитектура и стек книги

Книга компилируется из текстовых файлов в HTML и затем печатается в PDF через headless Chrome / Edge без тяжёлых сторонних зависимостей. Единственный внешний пакет Python — `pyyaml`.

### Структура проекта
- `src/book.yaml` — карта книги: метаданные (автор, ISBN, УДК/ББК, выходные данные), порядок частей и список глав.
- `src/frameworks/*.md` — исходники глав (по одной на файл с YAML front-matter).
- `src/pages/*.md` — фронт- и бэк-материалы (вступление, послесловие, источники).
- `src/schemes.py` — генератор векторных ч/б SVG-схем (18 визуальных типов).
- `src/icons.py` — векторные контурные иконки в сетке 24×24.
- `src/style.css` — строгая CSS-вёрстка физической книжной полосы (145×205 мм).
- `fonts/` — локальные шрифты `PT Serif` (для текста) и `Golos Text` (для схем и заголовков).

## 2. Ключевые команды сборки

Все команды запускаются из корня проекта `D:\Elton\Книга`:

```bash
# 1. Быстрая сборка HTML (для проверки в браузере за 1 секунду)
python build.py --html

# 2. Полная сборка книги (HTML + готовый печатный PDF в build/frameworks-of-life.pdf)
python build.py

# 3. Валидация вёрстки реальным движком Chrome (проверка переполнений страниц)
python measure.py

# 4. Сборка разворота обложки мягкого переплёта (4-я сторонка + корешок + 1-я сторонка)
python build_cover.py
# или с ручным расчётом корешка под бумагу:
python build_cover.py 272 0.106
```

## 3. Железные инварианты разворота и вёрстки

1. **Разворот:** 
   - Текст главы — строго на **ЧЁТНОЙ** (левой) полосе.
   - Схема — строго на следующей **НЕЧЁТНОЙ** (правой) полосе.
   - Сборщик `build.py` автоматически отслеживает чётность и вставляет пустые страницы при необходимости, чтобы разворот никогда не разорвался.
2. **Нулевой перелив (Overflow Zero):**
   - Текст левой полосы обязан умещаться ровно на одну физическую страницу (145×205 мм).
   - После любого редактирования или добавления текста **обязательно запускать `python measure.py`**.
   - Допустимый результат `measure.py`: только `переполнений нет`.
3. **Графика и цвет:**
   - Блок книги строго **чёрно-белый / grayscale** (чёрный `#000`, белый `#fff`, оттенки серого `#f4f4f4`, `#e6e6e6`, `#cfcfcf`). Никаких цветных RGB/CMYK плашек внутри блока.
   - Схемы имеют фиксированную ширину `560` единиц (112 мм полосы набора).

## 4. Как писать и добавлять новую главу

Файл создаётся в `src/frameworks/<id>.md`:

```yaml
---
id: pareto
title: Принцип Парето
subtitle: Пятая часть усилий даёт почти весь результат
icon: trend-up
source: Вильфредо Парето (1896)
link: Больше моделей — eltonlabs.org/base/frameworks-decisions
action: Что сделать сегодня
scheme_caption: Заголовок над схемой
scheme_note: Подпись под схемой
scheme:
  type: matrix2x2 # или cycle, flow, ladder, funnel, scale, venn, timeline, bars, cards, layers, branch, steps, compare, cross, stack, barbell, blank
  # параметры схемы
---
Текст главы с микроразметкой: **жирный**, *курсив*, #### Подзаголовок.
Объём: 180–230 слов, чтобы не вылезти за нижнее поле страницы.
```

Затем id главы добавляется в нужную часть в `src/book.yaml`.

## 5. Требования площадок публикации

### А. Литрес Самиздат (Литрес Авторы)

1. **Формат загрузки:**
   - Для сложных иллюстрированных книг с фиксированной вёрсткой принимается **PDF** (размер до **70 МБ**, от **4 страниц**).
   - В макете PDF должна быть одна страница книги на одну страницу PDF (пополосно, **не разворотами**).
2. **Требования к обложке для Литрес:**
   - Литрес для каталога и карточки книги требует **отдельную лицевую обложку (1-ю сторонку)** в формате JPG/PNG.
   - Размер: **2400 × 3405 px** (пропорция ~1:1.41 / формат 3:4 – 1:2), цветовой профиль **RGB**, разрешение **300 dpi**, вес до **5 МБ**.
   - Безопасная зона: важные элементы (имя автора, название) должны лежать внутри прямоугольника **1828 × 2838 px** (не ближе 100–150 px от края, чтобы не срезались превью и плашками 12+/16+/18+).
   - Лицевая обложка загружается отдельно в мастере публикации. Разворот обложки загружать в карточку электронной книги нельзя.
3. **Требования к метаданным и чистоте:**
   - Название на обложке должно строго буква в букву совпадать с названием в карточке публикации.
   - Имя автора: обязательно наличие фамилии («Элтон Абилов» или «Э. Н. Абилов»).

### Б. Печать по требованию (Ridero / T8 / Литрес POD)

1. **Геометрия блока:**
   - Обрезной формат: **145 × 205 мм**.
   - Поля: внутреннее корешковое не менее 18 мм (с учётом фрезеровки и клея 5 мм), внешнее 15 мм, верхнее 15 мм, нижнее 16 мм.
   - Число страниц: чётное (в проекте `build.py` автоматически выравнивает страницы).
2. **Обложка для печати мягкого переплёта:**
   - Подаётся разворотом одним файлом: `[4-я сторонка] + [корешок] + [1-я сторонка]`.
   - Вылеты под обрез (bleed): строго **+5 мм** со всех четырёх сторон.
   - Толщина корешка: рассчитывается по формуле `(число_страниц / 2) * толщина_листа`. Для офсета 80 г/м² коэффициент ~`0.106 мм`. Наш скрипт `build_cover.py` считает это автоматически.
3. **Цветовая модель:**
   - Блок: Grayscale / K-only.
   - Обложка: CMYK (или качественный RGB с переводом в профиль типографии при растрировании). Разрешение растра 300 dpi.
